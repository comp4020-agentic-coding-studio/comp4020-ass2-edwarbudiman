# Lecture authoring decisions

The maintained authoring standard is now [guidelines.md](../guidelines.md).
Read that file before creating or revising a week, including work in a separate
parallel session.

The user approved the revised Week 1 Wi-Fi lesson as the model: self-guided
explanations with no lecturer assumed, concepts introduced through a continuing
example, visible activity cues and worked responses. The original recipe and
paint examples were replaced at the user's request.

The guide consolidates content, design, source verification, parallel file
ownership and the user's preference to handle build and visual checks.
