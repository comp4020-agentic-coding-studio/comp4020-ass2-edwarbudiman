# Reflections

This course grew out of a personal concern: how can I understand what I read when there is so much information to take in? With so many social media posts, threads, and claims, I find it difficult to keep up. I stepped back and asked whether this was a course I would want to take, and how well I could design it.

The difficult part was explaining something I was still learning myself. I felt that I needed more experience with the subject to build the material well. I read ahead and used LLMs to help organise the content, but that did not fill the gap in my experience. The project became a lesson in how I manage work outside my expertise with LLM support.

## 1. What was the breakthrough that moved the work forward?

The breakthrough was having LLM agents discuss the course with one another and report back to me. I already had a direction in mind from my initial conversations, but their disagreements raised points I had not considered. This helped me think more deeply about the course and develop the idea further.

## 2. What did this work change about who I want to be as a software developer?

It did not change the kind of software developer I want to be. However, it highlighted how difficult it is to keep the output aligned with my intentions. Agents can finish tasks quickly, but I still need to check whether their work fits the purpose of the course. That is especially challenging when I am creating a course on a subject I also want to learn.
